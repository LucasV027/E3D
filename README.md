# E3D

E3D is a lightweight 3D framework and visualization tool built in C++ using OpenGL.  
It aims to provide a simple and clean foundation for creating graphical applications in C++ through OpenGL.

## Current Release (v0): Learning Phase

This release represents the learning phase in the development of E3D.  
It reflects experimentation and exploration to establish a solid foundation.

## Goals for v1

- Complete code refactor
- Layer system
- ImGui: add docking support
- Transform the editor into a simple showcase application
